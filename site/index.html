Every window in its place.

Planets is a free tiling window manager for macOS. Your windows fill the screen side by side, and nine workspaces are each one key away.

curl -fsSL https://raw.githubusercontent.com/vibeslop/Planets/main/install.sh | sh

Everything in one menu.

⌥B opens the Planets menu: what’s on each workspace, every shortcut, your settings, and an update when one is ready. Shortcuts leave alone the keys that type é and ñ, and follow the letters on Dvorak and AZERTY keyboards.

Settings in one text file.

Changes apply the moment you save. A mistake keeps the last working version running, and the menu says what’s wrong. Updates install by themselves while you’re away from the keyboard; auto_update = false turns that off.

Your windows always come back.

Planets keeps other workspaces’ windows in a corner of the screen. Quit it and every one comes back. If it crashes, it opens again by itself, with each window on its workspace.

One permission
Accessibility, which macOS requires before any app can move another app’s windows.
Easy to remove
Quit Planets from its menu, then delete it from Applications.
